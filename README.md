# CSC360-FinalProject
## Introduction

This project serves to demonstrate the basics of various software design patterns. In addition, it also houses examples of those design patterns in use.

## Structure

The code for design patterns is located under the `DesignPatterns` folder, and then further separated into different folders depending on the type of the design pattern. <br />
The different types are:
* Behavioral
* Creational
* Structural

Examples that use those design patterns are located under the `Examples` folder.

## Building

This project uses Visual Studio 2022 with the .NET 8.0 SDK for its buildsystem. Other buildsystems are not supported.

Once the requisite tools have been installed, all you should have to do is open the solution (`.sln`) file with Visual Studio.
